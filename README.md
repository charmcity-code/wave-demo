# Bean There Cafe: WAVE Demo Site

A small demo website used to show how to run the WAVE accessibility checker and read its report.

## Files

- `index.html`: the page content
- `styles.css`: the page styles

Some accessibility issues come from the HTML and some from the CSS, so both files are worth checking.

## More resources

- WAVE: https://wave.webaim.org
- A11y Coffee: https://a11y.coffee
